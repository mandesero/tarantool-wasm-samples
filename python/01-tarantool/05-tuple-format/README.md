# Python tuple-format API

Creates and reference-counts a tuple format built from key definitions.

Complete the [root setup](https://github.com/mandesero/tarantool-wasm-samples), then build and run from the repository root:

```sh
make build SAMPLE=python/01-tarantool/05-tuple-format
make run SAMPLE=python/01-tarantool/05-tuple-format
```

Expected result: `Test box tuple format done`. Generated bindings, `.tarawasm/`, and `dist/adder.wasm` are build artifacts and are intentionally ignored.
